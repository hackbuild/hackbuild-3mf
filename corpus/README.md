`packages/3mf/data/filament_template.json` and `template-diff.md` from the
gold file; `--check` fails when either drifts.

`inputs/` holds the writer agreement inputs that
`tools/py/test/test_agreement.py` builds with both writers.
`inputs/flex-pair-two.json` is generated: `npx tsc -b && node
tools/corpus/3mf/dump-input.mjs` writes it from the keys flex-pair build on
preset two as export3mf lays it out, and `--check` fails when it drifts.

This copy comes from hackbuild-fab `tools/corpus/3mf`; the generator paths
above are hackbuild-fab paths. Here the runner is `uv run --project py
corpus/run.py`, after `npm run build --prefix js`.
